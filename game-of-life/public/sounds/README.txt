Drop recorded sound effects here and set VITE_SFX_FILES=true (for example in
.env.local). The game then plays a file if it exists and falls back to its
built-in synthesized sound if not. With the flag off (the default) it only uses
the synthesized sounds and makes no file requests.

  lock-it-up.mp3   plays when you press Lock In

Only add audio you have the right to publish: this folder is served publicly
with the site, so a ripped clip from someone else's video is a takedown risk.
